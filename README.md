# riwi_python_csv

Actividad académica desarrollada en el curso **Desarrollo de Software Web & Analítica de Datos** (Riwi), correspondiente al **Módulo 1 – Fundamentos de programación en Python**.

## Descripción

Este repositorio contiene la solución de una práctica enfocada en:

- Manipulación de datos con Python.
- Lectura y escritura de archivos **CSV**.
- Edición de registros y persistencia de información.
- Validaciones de entrada y manejo de errores con `try/except`.

El objetivo pedagógico central es aprender a **conectarse a archivos CSV, procesar su contenido y guardar cambios de forma persistente**.

---

## Objetivos de aprendizaje

- Comprender cómo abrir y leer archivos `.csv` en Python.
- Transformar y validar datos provenientes de un archivo.
- Aplicar operaciones de gestión de registros (crear, consultar, actualizar y/o eliminar).
- Guardar cambios nuevamente en CSV para conservar datos entre ejecuciones.
- Mejorar la estructura del código mediante funciones y buenas prácticas básicas.

## Ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/miguelrodrica/riwi_python_csv.git
   cd riwi_python_csv
   ```

2. Ejecuta el archivo principal de la actividad (ajusta el nombre real):
   ```bash
   python app.py
   ```
   o:
   ```bash
   python main.py
   ```

3. Sigue las instrucciones del menú en consola para cargar, editar y guardar datos en CSV.
